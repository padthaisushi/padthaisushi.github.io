入札見積書作成アプリ

入札関係書類をアップロード → AIが仕様書から物品リストを作成 → 単価を入力 → 見積書を発行します。

1入札関係書類のアップロード

仕様書などのファイル（PDF / Word(.docx) / Excel(.xlsx, .xls) / テキスト(.txt, .csv)）をアップロードしてください。複数選択できます。

    2AIによる物品リスト作成

    上記のテキストをAI（Claude）に読み込ませ、購入する物品リスト（品名・型番・数量）を自動作成します。ご自身のAnthropic APIキーが必要です。APIキーはこのブラウザ内（localStorage）にのみ保存され、Anthropic API（api.anthropic.com）へ直接送信されます。サーバーには保存されません。

    Anthropicのドキュメントで最新のモデルIDをご確認の上、必要に応じて変更してください。

    3物品リスト・単価入力

    品名・型番・数量はAIの抽出結果から編集できます。各行の単価を入力すると金額が自動計算されます。

    消費税(10%): 0 円
    合計: 0 円
